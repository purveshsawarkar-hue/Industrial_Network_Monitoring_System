# Industrial Network Design and Monitoring System

## Project Description
This project simulates an industrial network using Cisco Packet Tracer. It connects multiple computers to a router, switch, and monitoring server.

## Technologies Used
- Cisco Packet Tracer
- Computer Networking
- IPv4 Addressing
- ICMP Ping
- HTTP Server

## Network Setup
- 1 Router
- 1 Switch
- 3 PCs
- 1 Monitoring Server

## Features
- Configured IP addresses and default gateways.
- Connected devices through a network switch.
- Tested connectivity using ping commands.
- Created a simple web-based monitoring dashboard.
- Verified communication between a client PC and the server with 0% packet loss.

## Server Address
`192.168.30.100`

## How to Run
1. Download the `.pkt` project file.
2. Open it using Cisco Packet Tracer.
3. Check device IP configurations.
4. Test connectivity using the ping command.
5. Open the monitoring server address in a PC's web browser.

## Learning Outcomes
Learned basic network configuration, IP addressing, connectivity testing, and HTTP server setup in a simulated industrial environment.
